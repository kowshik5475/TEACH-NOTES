# 📘 Academic Vault (TECH NOTES)

Academic Vault (TECH NOTES) is a centralized web-based platform designed to store, manage, and share academic resources such as notes, lecture materials, and assignments in an organized and secure way.

---

## 🚀 Live Demo

🌐 https://kowshik5475.github.io/TEACH-NOTES/

---

## 🎯 Objective

* Provide a single platform for academic materials
* Enable easy access to notes based on roles
* Improve organization of study resources
* Support both students and lecturers

---

## 👨‍💻 Features

### 👨‍🎓 Student

* View subject-wise materials
* Access notes by semester
* Download resources

### 👨‍🏫 Lecturer

* Upload academic materials
* Manage (edit/delete) own files
* Organize content by subject

### 🔐 Authentication

* Login & Registration system
* Role-based access (Student / Lecturer)
